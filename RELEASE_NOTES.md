# SolidCraft 0.3.0

Application native Windows en Rust, interface française pour la CAO mécanique et l'impression 3D.

- Accueil avec projets récents et reprise de session.
- Arbre de fonctions, esquisses sur plans et faces, cotation pilotante et relations géométriques.
- Bossages, découpes, révolutions, congés et chanfreins, perçages, répétitions et symétrie.
- Assemblages, vues éclatées, mise en plan SVG, nomenclature CSV et export STL.
- Licence GPL-3.0-only ; sources et instructions de compilation disponibles dans le dépôt.

## Téléchargement

Privilégier **SolidCraft-0.3.0-windows-x86_64.zip** : décompresser puis lancer SolidCraft.exe.
Cette archive inclut les exemples et les licences des dépendances.
L'EXE seul est également fourni ; conserver l'archive complète pour les notices et exemples.
SHA256SUMS.txt permet de vérifier les téléchargements.

Windows x86-64. Exécutable non signé.
Noyau géométrique maillé : les limites des fonctions sont décrites dans README.md.
